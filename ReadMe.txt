# Digit Recognition

Voice-based digit recognition project written in C++ for Windows. The program records or reads spoken digit samples, extracts cepstral features, builds a vector quantization codebook, trains one Hidden Markov Model per digit, and then recognizes digits from saved samples or from the microphone.

## How it works

The application uses a standard speech-recognition pipeline:

1. Read raw sample data from text files in `Digits/English/txt/` or from the microphone.
2. Remove DC offset and normalize the signal.
3. Split the signal into frames, apply a Hamming window, and compute LPC/cepstral features.
4. Train a 64-vector codebook using LBG clustering.
5. Convert each feature frame to a codebook index.
6. Train a 5-state HMM for each digit `0` to `9` using Baum-Welch.
7. Compare observation sequences with the trained models and choose the digit with the highest likelihood.

## Repository Layout

- `Digit_Recognition.cpp` - main application logic, feature extraction, codebook training, HMM training, and menu UI
- `stdafx.h`, `stdafx.cpp`, `targetver.h` - Visual Studio precompiled-header support files
- `Digit_Recognition.vcxproj` - Visual Studio C++ project file
- `Digits/English/txt/` - training and test utterances for digits `0` to `9`
- `codebook.txt` - saved codebook generated by the training option
- `model_digit_0.txt` to `model_digit_9.txt` - saved HMM models for each digit

## Prerequisites

This project is intended for Windows because it uses WinMM microphone APIs such as `waveInOpen` and `Sleep` from `Windows.h`.

Install:

- Visual Studio 2019 or 2022
- Desktop development with C++ workload
- Windows SDK

## Build

Open a **Developer Command Prompt for Visual Studio** in the project folder and run:

```bat
msbuild Digit_Recognition.vcxproj /p:Configuration=Release /p:Platform=Win32
```

To build the debug version instead:

```bat
msbuild Digit_Recognition.vcxproj /p:Configuration=Debug /p:Platform=Win32
```

You can also open `Digit_Recognition.vcxproj` directly in Visual Studio and build from the IDE.

## Run

After a successful build, run the executable from the output folder:

```bat
Release\Digit_Recognition.exe
```

For a debug build:

```bat
Debug\Digit_Recognition.exe
```

## Menu Options

When the program starts, it shows:

1. Train Models
2. Test Using Saved Files
3. Test Using Microphone
4. Quit

### 1. Train Models

This option reads training files from `Digits/English/txt/` using the naming pattern:

```text
254101040_E_<digit>_<utterance>.txt
```

It uses utterances `01` to `30` for training, builds `codebook.txt`, then trains and saves one model file per digit:

- `model_digit_0.txt`
- `model_digit_1.txt`
- `model_digit_2.txt`
- `model_digit_3.txt`
- `model_digit_4.txt`
- `model_digit_5.txt`
- `model_digit_6.txt`
- `model_digit_7.txt`
- `model_digit_8.txt`
- `model_digit_9.txt`

### 2. Test Using Saved Files

This option loads `codebook.txt` and the digit models if they are not already in memory, then tests utterances `31` to `40` for each digit and prints the predicted digit plus final accuracy.

### 3. Test Using Microphone

This option records about 3 seconds of audio from the default microphone, extracts speech-like frames, and classifies the spoken digit.

### 4. Quit

Exits the application.

## Important Notes

- The project expects the sample text files to remain in `Digits/English/txt/`.
- If `codebook.txt` or any `model_digit_*.txt` file is missing, run option 1 first.
- Microphone recognition works only on Windows with a working default recording device.
- The project currently targets Win32 from the Visual Studio project file.

## Expected Output Files

After training, the repository root should contain:

- `codebook.txt`
- `model_digit_0.txt` to `model_digit_9.txt`

These files are already checked into the repository so you can test immediately after building.
